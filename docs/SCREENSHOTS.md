# Aria piano — tablet and mobile gallery

[← README](../README.md) · [Live app](https://fischerjooo.github.io/Aria-piano/) · [Beta preview](https://fischerjooo.github.io/Aria-piano/beta/)

These are real Chromium snapshots of the stable release build, regenerated by **GitHub Actions when the live version publishes**. The tests actually navigate menus and lesson states; they do not substitute mock artwork. Screenshots represent browser emulation rather than physical hardware verification.

- **Tablet:** 1280 × 800 CSS pixels landscape; sheet also 800 × 1280 portrait.
- **Phone:** 915 × 412 CSS pixels landscape; sheet also 412 × 915 portrait.
- **Music:** longest available two-handed melody in the built catalogue, selected programmatically.
