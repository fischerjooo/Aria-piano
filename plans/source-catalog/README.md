## Conversion-ready priorities

- Blue Danube519: exact published C-major beginner main-theme arrangement, pickup labelled1 plus33 complete bars.100quarterbeats. No source fingerings. CC BY-SA4.0.
- Ode528: unchanged soprano from16-bar SATB hymn, Gmajor,64quarterbeats. Label as soprano-line reading study; it is not a published piano arrangement.
- PetzoldMinuet75: complete32-bar keyboard original, each16-bar half repeated. Preserve ornaments and simultaneous voices; block unsupported notation instead of approximating.
- Schumann647: pedagogical piano original with actual printed fingering. Preserve source fingerings, including substitutions; do not assign missing digits.

## Rights evidence

- [G Major primary license](https://mail.gmajormusictheory.org/Freebies/License.html) explicitly distinguishes personal practice/teaching from app redistribution. All12GMajor catalog entries are external-link-only until permission is obtained.
- Mutopia rights are checked per edition; no blanket assumption that an entire corpus has one license. BlueDanube519 is CC BY-SA4.0; Schumann647 is CC BY-SA2.5; other cataloged Mutopia editions are marked PublicDomain.
- [MakingMusicFun primary terms](https://www.makingmusicfun.net/htm/tos) require written consent for hosting elsewhere.

## Verification boundaries

- Actual downloaded LilyPond files are saved in sources/, with SHA256 values in catalog.json. These source files—not remembered melodies—must determine app event data.
- All cataloged source pages, exact edition identities, formats and licenses were checked through primary pages. Only BlueDanube and Ode complete bar counts are ready for direct event validation. Other scores need conversion validation before gameplay.
- Source ornaments, ties, chords, rests, voices and fingering cannot silently disappear during conversion.
- No modern MauroCosta book score was copied. Its contents image provides a repertoire target only.
